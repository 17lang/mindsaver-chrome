Mind Clipper

文件命名

空格、标点和表情统一为短横线；保留文字、数字和英文句点。优先使用文章发布日期，取不到用当天日期，长标题保持完整。

适用于 PDF、HTML 和 Markdown。标题已有日期时保留，不重复添加。同名文件自动编号，不覆盖原文件。

2026-11-13-文章标题.pdf

PDF / HTML 和默认下载的 Markdown 都保存到 Chrome 下载文件夹（可在 Chrome 设置里更改该目录）；只有 Markdown 能保存到 Obsidian 仓库。

Markdown 设置

两种位置都无需额外安装任何东西。

Markdown 和 PDF / HTML 一样保存到 Chrome 的下载文件夹，按「文件命名」页的规则命名。

必须与 Obsidian 仓库切换器里显示的名称完全一致、区分大小写。名称填错时 Obsidian 会提示找不到仓库。留空则使用当前打开的仓库。

只让 Obsidian 打开这个仓库，不会创建笔记。首次使用时 Chrome 会询问是否允许打开 Obsidian，请选择「允许」。

相对仓库根目录，例如 XO.Clippings；留空保存到仓库根目录。文件夹不存在时 Obsidian 会自动创建。
